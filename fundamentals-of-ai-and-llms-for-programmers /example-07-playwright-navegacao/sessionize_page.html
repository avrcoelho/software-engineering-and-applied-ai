FullStack Monitoring with Open Telemetry: End-to-End Observability for Modern Applicationsenespt

In this talk, I’ll show how to instrument applications end-to-end with OpenTelemetry, capturing metrics, traces, and logs across the entire request lifecycle. You’ll learn to pinpoint errors, understand why they happen, and fix them faster—guided by real-world examples and a starter template for quick adoption.
You’ll also see how to turn telemetry into automated insights using MCPs (Model Context Protocol) to generate reports from your observability stack—for example, using a Grafana MCP to produce incident summaries, release health reports, and “what changed?” diagnostics with open-source tooling.

Outline

- Why full-stack observability matters: from browser to database
- OpenTelemetry fundamentals: metrics, traces, logs, and context propagation
- JavaScript + Node.js instrumentation: where to add signals (and why)
- Correlation in practice: connecting errors, traces, logs, and user impact
- Detecting anomalies: SLOs, alerting, and actionable dashboards
- Export pipelines: OpenTelemetry Collector and common open-source backends
- AI-assisted ops with MCP: generating reports from Grafana (and other tools)
- A starter template + rollout strategy: incremental adoption without breaking prod

The Revolution of Embedded AI in the Browsersenespt

In this session, I’ll reveal how the web is entering a new era with AI running natively inside browsers. We’ll explore Chrome’s initiative to embed models directly in the runtime, the emerging consensus among browsers to define a common future for Web AI, and how this paves the way for a new “Web 4.0” — the agentic web. You’ll also gain insights into the latest Chrome AI APIs, see what’s already possible today, and discover how these capabilities will transform the way we build intelligent web applications.

Outline

- Embedded AI: Chrome’s initiative to ship models in the browser
- Cross-Browser Consensus: Aligning on the future of Web AI
- Web 4.0 Vision: The rise of the agentic web
- Chrome AI APIs: What developers can build today
- Real-World Use Cases: Practical examples of AI-powered web apps

Web AI Beyond Chat: Genetic Algorithms, RL, and Transformers.js on the Edgeenespt

Web AI isn’t just “call an LLM API.” In this talk, you’ll explore a practical toolkit for building AI features that run directly in the browser and Node.js—without per-request costs and with privacy-first defaults.

You’ll go beyond chat and cover Genetic Algorithms (optimization), Reinforcement Learning (decision-making agents), and Transformers.js as a runtime for running transformer-based models in JavaScript for vision, embeddings, classification, and more.

You’ll also see how to add a local knowledge layer using SQLite compiled to WebAssembly to enable RAG-style experiences fully on-device.

Outline

- Web AI without vendor lock-in: what’s possible today
- Genetic Algorithms: fast optimization and creative search
- Reinforcement Learning: agents that learn by trial and reward
- Transformers.js: running transformer models in browser/Node (not just chat)
- Local RAG: embeddings + retrieval + SQLite/WASM
- Shipping to mobile/desktop: Workers, performance, and UX patterns
